# ScreenMirror RU

Бесплатное приложение для передачи изображения экрана Android-телефона на Android TV по локальной сети Wi-Fi.

## Модули

- **ScreenMirror RU — Телефон** (`sender`) — запрашивает системное разрешение Android на захват экрана и отправляет поток H.264 на телевизор.
- **ScreenMirror RU — ТВ** (`receiver`) — принимает поток по TCP и декодирует его аппаратным видеодекодером Android.

## Как проверить текущую сборку

1. Установите APK `receiver` на Android TV и откройте приложение.
2. Узнайте локальный IP-адрес телевизора в настройках сети.
3. Установите APK `sender` на телефон, подключённый к той же Wi-Fi-сети.
4. Введите IP телевизора в приложении телефона и нажмите «Начать трансляцию».
5. Подтвердите системный запрос Android на захват экрана.

Порт передачи: TCP 8988. Используйте только в доверенной домашней сети.

## Сборка APK

GitHub Actions автоматически запускает `gradle assembleDebug` при изменениях в ветке `main`. После успешной сборки оба APK будут доступны в разделе **Actions → последний запуск → Artifacts**.

## Текущий статус и ограничения прототипа

Это ранний технический прототип, а не готовый релиз. Сейчас заложена передача видео H.264 по локальной сети с ручным вводом IP-адреса. Автоматическое обнаружение телевизора, QR-сопряжение, передача звука, выбор качества и полноценная обработка ошибок ещё требуют реализации и проверки на реальных устройствах.

Совместимость зависит от версии Android, кодеков и прошивки телевизора. Не считайте поддержку 1080p гарантированной до испытаний на конкретных устройствах.

## Требования проекта

- Android 8.0+ (API 26+) на телефоне и телевизоре.
- Оба устройства в одной локальной Wi-Fi-сети.
- Разрешение на захват экрана выдаётся пользователем при каждом запуске трансляции.
