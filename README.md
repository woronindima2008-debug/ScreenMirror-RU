# ScreenMirror RU

Бесплатное приложение для зеркалирования экрана Android-телефона на Android TV в одной локальной сети. Облачный сервер и компьютер для работы не требуются.

## APK

- **ScreenMirror RU — Телефон** (`sender`) — устанавливается на Android-смартфон.
- **ScreenMirror RU — ТВ** (`receiver`) — устанавливается на Android TV / ТВ-приставку.

## Возможности текущей ветки разработки

- Автоматический поиск телевизора через Android NSD/mDNS.
- Сопряжение сканированием QR-кода на экране телевизора; в QR находятся адрес и одноразовый код сессии.
- Резервный путь — автоматический поиск в локальной сети.
- Передача видео через WebRTC peer-to-peer по локальной сети.
- H.264 через доступные аппаратные кодеки WebRTC.
- Профили: сбалансированный (до 720p/30), высокий (до 1080p/30), плавный (до 1080p/60). Фактическое качество ограничивается устройством и сетью.
- Отображение на ТВ в режиме aspect-fit: изображение вписывается без обрезки.
- Отдельный аудиоканал AAC-LC с AudioPlaybackCapture на Android 10+ и переключателем в приложении.
- Если Android или исходное приложение запрещает захват аудио, видео продолжает работать без звука.
- Локальная WebSocket-сигнализация на ТВ; видеопоток идёт напрямую между устройствами. Для базового сценария интернет не нужен.

## Подключение

1. Подключите телефон и Android TV к одной домашней сети Wi-Fi/LAN.
2. Установите и откройте **ScreenMirror RU — ТВ** на телевизоре.
3. На телефоне откройте **ScreenMirror RU — Телефон**.
4. Нажмите «Найти телевизор автоматически» или отсканируйте QR-код с экрана ТВ.
5. Выберите качество, включите или отключите звук и нажмите «Начать трансляцию».
6. Подтвердите системный запрос Android на захват экрана. При запросе разрешите захват звука приложений.

## Сетевые порты

- TCP 8989 — локальная WebSocket-сигнализация и сопряжение.
- WebRTC — прямой медиатрафик между телефоном и телевизором (ICE host candidates для локальной сети).
- TCP 8990 — отдельный локальный аудиоканал AAC-LC.

Разрешите локальный обмен данными между устройствами в настройках роутера. Изоляция клиентов Wi-Fi (AP/client isolation) может блокировать соединение.

## Ограничения Android и защиты контента

- Системное разрешение MediaProjection запрашивается при каждом запуске трансляции.
- Захват звука приложений доступен начиная с Android 10 и требует разрешения RECORD_AUDIO и согласия пользователя.
- Исходное приложение должно разрешать AudioPlaybackCapture. DRM, защищённое видео, некоторые игры, звонки и приложения с политикой запрета могут не передавать звук или изображение.
- Разрешение 1080p/60 не гарантируется: оно зависит от аппаратных кодеков, температуры, производительности телефона, ТВ и Wi-Fi.
- WebRTC-видео и AAC-аудио передаются отдельными потоками, поэтому небольшая разница синхронизации возможна.
- На устройствах с ограничениями локальной сети или нестандартной реализацией mDNS может потребоваться повторный поиск либо ручное сопряжение QR-кодом.

## Сборка

GitHub Actions собирает оба debug APK командой `gradle --no-daemon assembleDebug`. APK публикуются как артефакт `ScreenMirror-RU-debug-apks` в соответствующем запуске Actions.

## Статус

Ветка `feature/webrtc-p2p` содержит полную реализацию первого сквозного варианта: QR/NSD-сопряжение, WebRTC-видео и AAC-аудио. Успешная CI-сборка подтверждает компиляцию APK, но не заменяет испытания на реальном телефоне и Android TV. До теста на целевых устройствах совместимость и качество не считаются подтверждёнными.
