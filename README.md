# ScreenMirror RU

Бесплатное приложение для зеркалирования экрана Android на Android TV по локальной сети Wi-Fi.

## Состав

- `sender` — приложение-отправитель для телефона.
- `receiver` — приложение-приёмник для Android TV.

## Статус

Начальная структура проекта. Перед выпуском APK необходимы сборка, проверка совместимости и тестирование на реальных устройствах.

## Сборка

Проект использует Gradle Wrapper и GitHub Actions. APK будут публиковаться как артефакты CI после успешной сборки.
