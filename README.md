# ScreenMirror RU

Два приложения одного проекта:
- **ScreenMirror RU** для Android-телефона — отправляет изображение и поддерживаемый системный звук.
- **ScreenMirror RU** для Android TV — принимает и отображает трансляцию.

## Подключение

Телефон и телевизор должны находиться в одной локальной сети Wi-Fi. На ТВ отображается QR-код для сопряжения. На телефоне можно отсканировать QR-код, найти телевизор автоматически через Android NSD или указать IP-адрес вручную.

## Управление

Во время трансляции на телефоне доступна плавающая панель поверх других приложений. Её можно перемещать и сворачивать. Кнопки «Звук» и «Изображение» управляют потоками независимо. При остановке изображения ТВ показывает «Передача приостановлена». Завершение трансляции доступно отдельной кнопкой.

## Качество

Отправитель запрашивает аппаратное кодирование H.264, до 3840×2160 при наличии подходящего экрана и кодека, с приоритетом высокого битрейта и малой задержки. Фактические разрешение, частота кадров и плавность зависят от телефона, ТВ, кодеков и Wi-Fi. Если устройство не поддерживает выбранный режим, может потребоваться более низкое разрешение.

Звук передаётся через Android Playback Capture (Android 10+). Некоторые приложения, защищённый контент и DRM могут запрещать захват аудио. На Android 8/9 трансляция работает без системного аудиозахвата.

## Сборка и проверка

Автоматические сборки при push отключены, чтобы не создавать промежуточные APK. Итоговая сборка запускается вручную через GitHub Actions после проверки исходников.

Исходники ещё требуют компиляционной проверки и испытания на реальном телефоне и Android TV. Не считать эту ветку готовым релизом до успешной итоговой сборки и проверки устройств.
